02它解决的问题

不是"把文字读出来"，而是"让一个角色的声音，在 50 集里听起来是同一个人"。

🎨 音色设计器

输入"老年女声"→ 规则/LLM 翻译 → 直接生成最匹配的音色 → 波形可视化试听。

🎭 音色混合器

主参考 × 辅助参考 → 多说话人融合出独特新声线（55 真人参考两两组合 = 数千种潜在音色）。

🎚️ 去 AI 味后处理

呼吸声注入 + 微颤动 + EQ 塑形 + 压缩限幅 + 混响 + LUFS（off/clean/natural 三档，配方级控制）。

🎭 角色表 Cast

角色 ↔ 配方 ↔ 情绪 持久化为 YAML，跨集听感不漂移。

🔧 单句修复

批量后某句错了或改台词 → 只重跑那一句，不用整集重来。

📦 剪映交付包

一键导出：按集时间轴自动累计的 SRT 字幕 + 导入说明（音频命名即轨位）。

💰 成本路由 + 降级链

本地(0元)→GPT-SoVITS(0元)→edge-tts(0元)→MiniMax(按量)；宿主不可用自动降级，不报错。

🔒 合规门禁

音色溯源 + 克隆门禁（仅自有授权声音）+ 敏感词过滤。不做也不允许侵权用途。

03跑起来（3 步）

Python 3.11+。零配置即可用——edge-tts 兜底，不需要任何 key。

# 1. 安装（建议 uv）
uv venv .venv --python 3.11
uv pip install --python .venv -e . -i https://pypi.tuna.tsinghua.edu.cn/simple

# 2. 看引擎状态
voicecast engines

# 3. 描述 → 直接生成一个音色（试听）
voicecast design "老年女声"

# Web 界面（推荐入口，Windows 双击 web.bat）
python -m uvicorn voicecast.web.server:app --host 127.0.0.1 --port 7860
引擎成本说明
GPT-SoVITS（本地）0 元生产级中文克隆（多说话人融合 / 情感 / 语速）
F5-TTS（本地）0 元完全离线零样本克隆；GPT 离线时的自动降级目标
edge-tts0 元零 key 免费兜底，8 个中文音色 + 变调配方
MiniMax按量可选插件，无 key 自动跳过
